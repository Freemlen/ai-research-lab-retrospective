# Project Timeline

## 1. Event Horizon numerical program

The project began as a numerical/theoretical exploration of scalar-field gravitational collapse. A canonical finite-eta, U=0 solver was frozen and tested. The numerical program then explored several hand-designed directions in initial-data space.

### DYN0 — baseline
Canonical reference calculation with transient Jordan trapped-sphere diagnostics followed by finite-time central dispersal. This is not an event-horizon result and not an infinite-time scattering theorem.

### DYN1 — amplitude family
Nine sampled amplitudes were studied. All sampled cases remained within the finite-time dispersive classification used by the project. This is a finite enumerated sample, not an open neighborhood.

### DYN2 — paired momentum
Signed radial momentum perturbations were tested. A late endpoint inward-flux signal initially looked interesting.

### DYN2R1 — diagnostic repair
An exact/same-input eta=0 dispersive control reproduced the suspicious late inward flux. The project therefore rejected endpoint flux sign as a material-retention discriminator and replaced it with conservation/window/radius transport diagnostics. This is one of the clearest durable methodological results of the project.

### DYN3 Stage A — equal-enclosed-mass width variations
Several admitted widths were tested. The sampled family remained finite-time dispersive within the declared scope.

### DYN3 Stage B — orthogonal shape direction
A first-order shape tangent orthogonal to amplitude, equal-energy width, and first energy variation was constructed. Physical classification never closed: trajectory/static control failures and then a bounded A-final protocol left the direction CONTROL_LIMITED. Passing nonzero static samples existed, but no contract-valid release pair was obtained.

## 2. Retrospective DYN audit

A canonical retrospective packet was assembled. The final scientific conclusion was that the scoped DYN core was scientifically supported, while historical review provenance for early stages was incomplete. No earned scientific DYN result required recomputation.

This audit also forced a crucial distinction:
- scientific support,
- review/provenance support,
- and historical acceptance records are different things.

## 3. DYN4 — fixed-energy two-pulse temporal focusing

A prospective two-pulse timing protocol was built and reviewed. Eighteen CONTROL_ONLY trajectories were run through T=4 across six delays and three grids.

Full physical release to T=256 was withheld because the conjunctive early-admission gate did not close:
- literal CFL cap discrepancy;
- unresolved J4 attribution/finite-eta transfer;
- three outer momentum-L2 refinement issues.

Therefore:
- zero T=256 search trajectories;
- zero D/C/U physical outcomes;
- temporal focusing remains NOT_ESTABLISHED.

## 4. Novelty/relevance audit

A later adversarial literature/value audit concluded:
- technically credible local evidence exists;
- no major new GR physical result had been established;
- no broadly validated new numerical method had been demonstrated;
- the strongest reusable asset was the false-positive diagnostic example and its repair;
- automatic expansion of the physics program should stop.

Canonical verdict:
TECHNICALLY_SOUND_LOW_EXTERNAL_VALUE.

## 5. WILD2 / PROJECT TENET

A narrower candidate survived: variational/minimal-seed characterization of a gravitational critical surface. The broad “Tenet mathematics” novelty claim did not.
